# What doeth life

Experiencia interactiva en Three.js: una moneda-línea, una ranura y un personaje low poly para pintar.

## Cómo correrlo

```bash
npm install
npm run dev
```

Abre la URL local (por defecto `http://localhost:5173`).

## Cómo se juega

1. Arrastra la línea negra (moneda de canto) para levantarla.
2. Al levantarla aparece una ranura: suéltala encima para insertarla.
3. Aparece un personaje low poly (off-white + wireframe charcoal).
4. Arrastra fuera de la figura para rotar; arrastra sobre ella para pintar.
5. Elige color en la paleta inferior (incluye off-white para “borrar”).

## Stack

- Vite
- Three.js
- Cannon-es (física de la moneda)

## Paleta

- Off-white `#F5F2EB`
- Charcoal `#2C2C2C`
